RubiGUI-PPT v1.0 - ご利用ガイド
=================================

このアプリケーションは、PowerPointファイル（.pptx）の本文から語句と読みを
抽出し、TSV形式およびルビ付きPowerPointファイルを生成するためのツールです。
Wordの「ルビ編集ツール（RubiGUI）」のPowerPoint版にあたります。

------------------------------------------------------------
■ フォルダ構成
------------------------------------------------------------

RubiGUIforPPTX/
├─ RubiGUI_PPT_V1.0.py     … アプリ本体
├─ sudachi.json            … 辞書設定（相対パス）
├─ system_full.dic         … Sudachi辞書ファイル
├─ override.json           … 読みの強制指定ファイル（任意）
├─ ruby_settings.json      … ルビ設定の保存ファイル（自動生成）
├─ requirements.txt        … 必要なPythonライブラリ一覧
└─ readme.txt              … 本ガイド

※ これらのファイルは同じフォルダに置いてください。
※ アプリはフォルダ内のファイルを参照して動作します。
　 本体だけをフォルダから移動すると動作しなくなります。
※ Word版と違い、PowerPoint側にマクロ（Module1.bas）を入れる必要はありません。
　 すべてアプリ側からPowerPointを操作して完結します。

------------------------------------------------------------
■ バージョンの確認方法
------------------------------------------------------------

アプリのウィンドウタイトルおよび画面右下に「RubiGUI-PPT v1.0」と表示されます。
不具合や質問を連絡する際は、この表示されているバージョン番号も
あわせてお伝えください。

------------------------------------------------------------
■ 動作条件
------------------------------------------------------------

    ・Windows と Microsoft PowerPoint がインストールされていること
      （アプリがPowerPointを自動で起動して操作します）
    ・Python 3 と requirements.txt のライブラリ
      　インストール例：
      　　python -m pip install -r requirements.txt
    ・ネットワーク接続は不要です。すべてお使いのパソコンの中だけで
      処理が完結し、外部にファイルや文章が送信されることはありません。

※ 処理中はPowerPointのウィンドウが自動的に開きます。
　 文字の位置を正確に測るために画面表示が必要なためで、正常な動作です。
　 処理が終わるまでPowerPointを手動で閉じたり操作したりしないでください。

------------------------------------------------------------
■ 初回起動時に自動生成されるフォルダ
------------------------------------------------------------

デスクトップに以下のフォルダが自動生成されます（Word版と共用です）：

~/Desktop/ルビ振り/ルビデータ/
    語句と読みのTSVファイルが保存されます。

~/Desktop/ルビ振り/出力（ルビ付き）/
    ルビ付きのPowerPointファイルが保存されます。

既に存在する場合はそのまま使用されます。
（OneDriveでデスクトップが同期・リダイレクトされている環境でも、
　実際にエクスプローラー上で表示される「デスクトップ」の場所に作成されます。）

■ 基本的な使い方
------------------------------------------------------------

● 1ファイルをドロップした場合
    - 自動処理は行われません（語句抽出・表示のみ）。
    - 読みを編集したい語句をダブルクリックすると編集画面が開きます。
    - 編集画面には「保存」と「削除」の2つのボタンがあります。
        ・保存：語句・読みを修正して確定します。
                ※語句・読みのどちらかを空欄にしたまま「保存」を押すと
                　エラーになり保存できません（空欄行がリストに残る不具合対策）。
        ・削除：確認ダイアログの後、その語句をリストから完全に削除します。
                この語句にはルビが付与されなくなります。
                ※語句を削除したい場合は、空欄で保存するのではなく
                　必ずこの「削除」ボタンを使ってください。
    - 「TSV保存」→「ルビ付きPowerPoint出力」を手動で押してください。
    - 辞書編集ボタンは読みを強制したい語句の登録に使います。必要に応じて利用してください。
    - 辞書再適用ボタンは編集した辞書を現在読み込んでいるファイルの語句一覧に
      反映させるボタンです。一度登録した辞書は次回以降自動で反映されます。

● 複数ファイルをドロップした場合
    - 自動で TSV 出力 → PowerPoint 出力まで行われます。
    - 確認ダイアログは表示されません（語句の個別編集はできません）。
    - 個別に読みを確認・修正したい場合は、事前に override.json（辞書編集）に
      登録しておくか、1ファイルずつドロップして処理してください。

● フォルダ選択
    - 📁 一括処理：確認なしで全ファイルを処理
    - 一括処理（確認あり）：各ファイルごとに確認しながら処理
        確認・編集方法は1ファイルをドロップした場合と同様です（削除ボタンも使用可）。
    - ▶ 次へ：逐次処理時に次のファイルへ進む

■ ルビ設定
------------------------------------------------------------

画面右側の「ルビ設定」で、ルビの見た目を調整できます。
変更した値は ruby_settings.json に保存され、次回起動時にも引き継がれます。

● ルビの大きさ（親文字の％）　既定値 50
    - 親文字に対するルビのフォントサイズの比率です。
    - 10〜100 の範囲で指定できます。

● 行間の倍率（2行以上のとき）　既定値 1.5
    - 2行以上のテキストにルビを振るとき、ルビを置く余白を作るために
      行間をこの倍率で広げます。1行だけのテキストでは行間を変更しません。
    - 1.1〜4.0 の範囲で指定できます。1.0 にすると余白がゼロになり、
      ルビが上の行の文字に完全に重なってしまうため指定できません。
    - ※既定の「ルビ50％・行間1.5倍」は、広がった余白の高さとルビの高さが
      　ちょうど一致する組み合わせです。ルビを大きくする場合は行間の倍率も
      　あわせて大きくしてください（例：ルビ60％なら行間1.6倍）。

● ルビの位置調整（pt）　既定値 0
    - ルビを親文字からさらに離したいときに指定します。
    - 正の値でルビが親文字から遠ざかります（横書きなら上、縦書きなら右）。
    - -50〜50 の範囲で指定できます。

● タイトル枠も対象にする　既定値 オフ
    - オフのあいだ、タイトル枠・サブタイトル枠にはルビが振られません。
    - チェックを切り替えると語句一覧も自動的に取り直されます。

※ 数値として読み取れない文字や範囲外の値を入れた場合は、警告を表示して
　 その項目だけ既定値で処理します。

------------------------------------------------------------
■ override.json（読みの強制指定）
------------------------------------------------------------
    - アプリ起動時に辞書編集ボタンで編集するほか、override.jsonをメモ帳などで
      開き、直接編集も可能です。
    - Word版の override.json をそのまま流用できます。

以下の形式で語句の読みを上書きできます：

{
    "名古屋": "なごや",
    "愛知県": "あいちけん"
}

TSV出力・PowerPoint出力の両方に反映されます。

------------------------------------------------------------
■ ルビが振られない語句について（仕様）
------------------------------------------------------------

以下に該当する語句は、意図的にルビ付与の対象外としています。

    ・ひらがなのみの語句
    ・カタカナのみの語句
    ・数字のみの語句（半角/全角、「.」「,」「-」「：」「/」等の区切りを含む）
    ・半角英字のみの語句（英単語・アルファベット略語など。例：Word、AI など）
      ※半角数字や一般的な区切り記号（スペース . , - _ ' & / ( )）が
        混ざっていても英字のみとみなします。
    ・1文字の語句
    ・読みが語句自体と同じになる語句
    ・漢字をまったく含まない語句

上記に該当しても読みを付けたい場合は、override.json（辞書編集）に
その語句と読みを登録してください。登録した語句は上記の除外ルールより
優先され、必ずその読みが使用されます。

------------------------------------------------------------
■ ルビの付き方について（仕様）
------------------------------------------------------------

PowerPointにはWordの「ルビ」機能に相当する仕組みがありません。
そのため本ツールは、ルビ用のテキストボックスを新しく作って親文字の
真上（縦書きの場合は右側）に配置する方式をとっています。
配置後もルビは独立した図形なので、1つずつ自由に位置や文字を編集できます。

● ルビを振る単位
    - 連続した漢字のかたまり（漢字ブロック）ごとに、別々のテキストボックスで
      配置します。送り仮名の上にはルビが乗りません。
        例：「取り引き」→「取」に「と」、「引」に「ひ」
        例：「見直し」　→「見直」に「みなお」
    - 送り仮名と読みの対応が取れない語句（数字混じりなど）は、
      例外的に語句全体へ1つのルビを配置します。

● 親文字の書式
    - 縦書き／横書き・フォントの種類・フォントサイズ・文字色は
      ルビ振り前のまま変更されません。
    - ルビには親文字と同じフォント・同じ色が使われ、サイズだけが
      「ルビ設定」で指定した比率に縮小されます。

● 行間の調整
    - 2行以上のテキストにルビを振る場合は、先に行間を広げてルビの
      置き場所を作ってから配置します。
    - PowerPointの行間は各行の上（縦書きでは各列の右）に余白を作るため、
      1行目のルビも図形の枠内に収まります。
    - 1行だけのテキストは行間を変更しないため、ルビが図形の枠より
      少し上（縦書きでは右）にはみ出して表示されます。

● グループ化
    - テキストボックスの場合は、親文字とそのルビをまとめて1つのグループに
      します。移動やコピーがまとめて行えます。
    - プレースホルダ（レイアウトのタイトル枠・本文枠）は、PowerPointの仕様上
      他の図形とグループ化できません。この場合はグループ化を行わず、
      ルビを個別のテキストボックスとして配置します。

● アニメーション
    - 元の図形にアニメーションが設定されていた場合、同じ種類・同じ順序・
      同じ開始方法・同じ遅延・同じ継続時間でグループに設定し直します。
    - プレースホルダの場合はグループ化しないため、各ルビへ同じアニメーションを
      複製し、開始方法を「直前の動作と同時」にして親と同時に再生されるように
      します。ルビの数だけアニメーションの項目が増えますのでご了承ください。
    - 段落ごとに分けて表示するアニメーション（テキストの動作）や、
      クリックのきっかけ（トリガー）を使ったアニメーションは、
      グループ化の際に1つの効果にまとめられます。

● ルビが振られない場所
    - タイトル枠・サブタイトル枠（「タイトル枠も対象にする」がオフのとき）
    - フッター・ヘッダー・日付・スライド番号の枠
      （全スライド共通の文字に同じルビが量産されるのを防ぐため常に対象外です）
    - 表（テーブル）の中の文字
    - 四角形・矢印・吹き出しなどの図形の中の文字
    - すでにグループ化されている図形の中の文字
    - ノート（発表者用メモ）
    - 回転している図形
    - 「すべてのテキストを90度回転」など、行が左から右へ進む縦組みの図形
      （日本語のルビの位置が定義できないため）

------------------------------------------------------------
■ 出力形式
------------------------------------------------------------

● TSVファイル
    - 文字コード：UTF-8（BOM付き）
    - Excelでダブルクリックしても文字化けしません。
    - Word版はcp932で出力していたため一部の特殊文字を含む語句が除外されて
      いましたが、PowerPoint版ではその制限がなくすべての語句を出力します。

● PowerPointファイル（.pptx）
    - 「~/Desktop/ルビ振り/出力（ルビ付き）/元のファイル名（ルビ）.pptx」
      として保存されます。
    - 元のファイルは一切変更されません。先に出力先へコピーを作り、
      そのコピーだけを編集しています。
    - .ppt / .pptm / .pdf などは非対応です。

------------------------------------------------------------
■ 再実行したときの動作
------------------------------------------------------------

一度ルビを振ったファイルをもう一度処理しても、ルビが二重になったり
行間がどんどん広がったりすることはありません。

    - 配置したルビとグループには、画面に表示されない目印が記録されています。
    - 再処理のときはこの目印をたどってグループを解除し、古いルビを削除し、
      行間・自動調整・図形名・アニメーションを元の状態へ戻してから
      あらためてルビを振り直します。
    - そのため、辞書を直して出力し直したい場合は、出力済みのファイルを
      そのままドロップして構いません。

■ よくあるトラブルと対策
------------------------------------------------------------

× 辞書が読み込めない
    → sudachi.json の systemDict が絶対パスになっている可能性。
    対策： "systemDict": "system_full.dic" になっているか確認。

× PowerPointの起動に失敗しましたと表示される
    → PowerPointがインストールされていないか、別の処理で応答待ちの可能性。
    対策：PowerPointを一度手動で起動して閉じ、もう一度実行してください。
      　　起動しっぱなしのPowerPointが残っている場合はタスクマネージャーから
      　　終了させてください。

× 処理の途中でPowerPointの画面がちらつく／勝手に動く
    → 文字の位置を測るためにスライドを表示しながら処理しています。仕様です。
    対策：処理が終わるまで操作しないでお待ちください。

× ルビが1件も配置されない
    → 語句一覧が空か、対象外の場所にしか文字が無い可能性。
    対策：語句一覧に語句が出ているか確認してください。文字が表（テーブル）や
      　　図形の中、あるいはタイトル枠にしか無い場合は仕様上対象外です。
      　　タイトル枠に振りたい場合は「タイトル枠も対象にする」をオンにしてください。

× ルビが親文字と重なる／離れすぎている
    → 「行間の倍率」と「ルビの大きさ」の組み合わせが合っていない可能性。
    対策：ルビの比率を上げたときは行間の倍率も同じくらい上げてください。
      　　微調整は「ルビの位置調整（pt）」で行えます。

× ルビが図形の枠からはみ出す
    → 1行だけのテキストは行間を広げないため、ルビが枠の外に出ます。仕様です。
    対策：気になる場合は図形の高さ（縦書きなら幅）を少し広げるか、
      　　テキストの位置を下げてください。

× 文字が図形からあふれるようになった
    → 「図形に合わせてテキストを調整」（自動調整の縮小）が設定されていた図形です。
    対策：フォントサイズを変えないことを優先して自動調整を解除しているため
      　　起こります。出力後に図形の大きさを調整してください。

× タイトルにルビが振られない
    → 既定ではタイトル枠・サブタイトル枠は対象外です。
    対策：「ルビ設定」の「タイトル枠も対象にする」にチェックを入れてください。

× 語句を削除したのに空欄の行がリストや出力に残る
    → 語句・読みを空欄にして「保存」するのではなく、編集画面の
      「削除」ボタンを使用してください。空欄のままの保存はエラーになり、
      保存されない仕様になっています。

------------------------------------------------------------
■ ログファイル（rubigui_ppt.log）について
------------------------------------------------------------

エラーなどが起きた場合、実行フォルダに rubigui_ppt.log が自動生成されます。
不具合報告の際はこのファイルをそのまま提供してください。

    - 1ファイルあたり最大5MBまで記録し、上限に達すると自動的に
      rubigui_ppt.log.1／.2／.3 へローテーション（世代管理）されます。
    - 古い世代（4世代より前のログ）は自動的に削除されるため、
      ログファイルが無制限に肥大化することはありません。
    - 直近の作業内容ほど新しい rubigui_ppt.log（拡張子なし）に記録されています。
      連絡の際は rubigui_ppt.log と、可能であれば rubigui_ppt.log.1 も
      あわせてお送りいただけると調査がスムーズです。

■ 注意事項
------------------------------------------------------------

・完全なルビ振りを保証するものではありません。

・ルビは独立したテキストボックスです。出力後に親文字を編集しても
　ルビは自動では追従しません。本文を直した場合はルビも手で直すか、
　直した本文のファイルをもう一度処理し直してください。
・本ツールは無償提供です。サポートはありません。
・サポート予定はありませんが何か困ったことや改善点があれば個別にお声がけください。対応するかもしれません。
・お問い合わせの際は、画面右下に表示されているバージョン番号（例：RubiGUI-PPT v1.0）と
　rubigui_ppt.log を一緒にお送りいただけると対応しやすくなります。
