RubiGUI_v1 - ご利用ガイド（exe版）
=================================

このアプリケーションは、日本語テキストから語句と読みを抽出し、
TSV形式およびルビ付きWordファイル（.docx）を生成するためのツールです。
Python や追加インストールは不要で、同梱フォルダのまま実行できます。

------------------------------------------------------------
■ フォルダ構成（配布フォルダ）
------------------------------------------------------------

RubiGUI/
├─ RubiGUI_v1.exe          … アプリ本体
├─ sudachi.json            … 辞書設定（相対パス）
├─ system_full.dic         … Sudachi辞書ファイル
├─ override.json           … 読みの強制指定ファイル（任意）
├─ Module1.bas             … Wordマクロ（ルビ付与用）
└─ readme.txt              … 本ガイド

※ これらのファイルは同じフォルダに置いてください。
※ Python や pip のインストールは不要です。
※ RubiGUI_v1.exe はフォルダ内のファイルを参照して動作します。
　フォルダごと任意の場所に置き、exe のショートカットを作成してご利用ください。
　exe 本体をフォルダから移動すると動作しなくなります。

------------------------------------------------------------
■ 初回起動時に自動生成されるフォルダ
------------------------------------------------------------

デスクトップに以下のフォルダが自動生成されます：

~/Desktop/ルビ振り/ルビデータ/
    語句と読みのTSVファイルが保存されます。

~/Desktop/ルビ振り/出力（ルビ付き）/
    ルビ付きのWordファイルが保存されます。

既に存在する場合はそのまま使用されます。

------------------------------------------------------------
■ 基本的な使い方
------------------------------------------------------------

● 1ファイルをドロップした場合
    - 自動処理は行われません。
    - 読みを編集したい部分をダブルクリックすると編集することが可能です。
　　- 削除したい場合は語句・読みともに削除してください。
    - 「TSV保存」→「ルビ付きWord出力」を手動で押してください。
　　- 辞書編集ボタンは読みを強制したい語句の登録に使います。必要に応じて利用してください。
　　- 辞書再適用ボタンは編集した辞書を現在読み込んでいるwordの読みに反映させるボタンです。一度登録した辞書は次回以降自動で反映されます。

● 複数ファイルをドロップした場合
    - 自動で TSV 出力 → Word 出力まで行われます。
    - 確認ダイアログは表示されません。

● フォルダ選択
    - 📁 一括処理：確認なしで全ファイルを処理
    - 一括処理（確認あり）：各ファイルごとに確認しながら処理
　　　確認・編集方法は1ファイルをドロップした場合と同様です。
    - ▶ 次へ：逐次処理時に次のファイルへ進む

------------------------------------------------------------
■ override.json（読みの強制指定）
------------------------------------------------------------
　　- RubiGUI_v1.exe起動時に辞書編集ボタンで編集するほか、override.jsonをメモ帳などで開き、直接編集も可能です。

以下の形式で語句の読みを上書きできます：

{
    "名古屋": "なごや",
    "愛知県": "あいちけん"
}

TSV出力・Word出力の両方に反映されます。

------------------------------------------------------------
■ 出力形式
------------------------------------------------------------

● TSVファイル
    - 文字コード：CP932（Shift_JIS互換）
    - Excelで文字化けしないよう配慮されています。

● Wordファイル（.docx）
    - Module1.bas のマクロを使用してルビを付与します。
    - .doc / .rtf / .pdf などは非対応です。

------------------------------------------------------------
■ Wordマクロ（Module1.bas）の導入方法
------------------------------------------------------------

1. Word を開く
2. 開発タブ → VBAエディタを開く(もしくはAlt + F11)
   開発タブがない場合　→　ファイル→オプション→リボンのユーザー設定の右の一覧の開発にチェック
3. Module1.bas をNormalにインポート
   Normalを選択した状態で右クリック→ファイルのインポート→RubiGUIフォルダ内のModul1.basを選択
   ※Project(文書１)などにインポートすると他のファイルでマクロが使用できません。
4. マクロを有効化
5. セキュリティ警告が出る場合は「コンテンツを有効化」

------------------------------------------------------------
■ よくあるトラブルと対策
------------------------------------------------------------

× exe が起動しない
    → SmartScreen がブロックしている可能性があります。
    対策：［詳細情報］→［実行］を選択してください。

× 辞書が読み込めない
    → sudachi.json の systemDict が絶対パスになっている可能性。
    対策： "systemDict": "system_full.dic" になっているか確認。

× Word マクロが動かない
    → マクロが無効になっている可能性。
    対策：開発タブからマクロを有効化し、Module1.bas を再インポート。

× TSV が文字化けする
    → 現在は CP932（Shift_JIS互換）で出力しているため通常は文字化けしません。
      もし Excel が正しく開けない場合は、Excel 側の設定を確認してください。
